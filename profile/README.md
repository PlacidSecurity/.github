# Placid Security

**Practitioner-led cybersecurity consulting from Lake Placid, New York.**

Placid Security is the independent practice of Kevin T. Geil, GIAC Security Expert (GSE #357) and CISSP, with 15+ years across offensive security, incident response, and governance, risk, and compliance. Every engagement is delivered by me, personally, not passed to junior analysts.

### What I do

- **Penetration testing:** network, Active Directory, and web application testing with evidence-based, actionable reporting
- **Incident response:** ransomware and business email compromise investigations, Microsoft 365 compromise analysis, and recovery support
- **GRC and CISO advisory:** building and maturing security programs, policy development, and compliance readiness for organizations without a full-time security leader

### Open source

| Project | Description |
|---|---|
| [**PowIRShell**](https://github.com/PlacidSecurity/PowIRShell) | PowerShell toolkit for incident response and Active Directory auditing. Includes `Get-M365CompromiseInfo`, which analyzes Microsoft 365 Unified Audit Log exports and enriches suspect IPs with IPinfo.io, IPQualityScore, and Scamalytics threat intelligence. |

The tools here come out of real engagements. If they save you time during an incident, that's the point. Issues and pull requests are welcome.
